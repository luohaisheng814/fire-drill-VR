# 第 49 轮修改与上传日志

## 1. 本轮需求与做法

需求（用户原话要点）：

1. **情形 1 与情形 2 是完全独立的演练**，不再和电气起火、纸张起火、茶水间起火发生任何联系。
2. **操作教学**要讲清「普通员工」与「火灾初期应对责任人」在电气、纸张、茶水间三种情景下分别应做什么决断；玩家读完只**返回「办公室消防知识演练」主面板**再自行选择，不能直接开始演练。
3. 在电气、纸张、茶水间三个情景以及两种独立情形中，**每面墙都在合适距离安装手动火警报警按钮**。
4. 检查三台灭火器，全部**竖放挂墙**、位置合理、可取用，不被家具挡住。
5. 结合**韩国官方消防安全知识**，重新梳理逃生路线、灭火知识与注意事项。
6. **以玩家视角测试**（眼高 1.62 米、1600×900），通过后提交并推送到 GitHub，生成本日志。

做法：

- 把「两种情形」做成一套**独立火情演练**：不加载任何 `scenarios[]` 起火情景，使用原操作演练地板火 `BaseFire000` 作为唯一主火，配独立烟雾、独立出生点、独立灭火点位；不设电源，不要求断电，标题固定为「独立火情演练」。
- 四种墙面按钮统一挂到北、西、南、东四面墙，离地约 1.30 米；四种演练共用同一组按钮，运行时统一订阅 `DrillScenario.OnAlarmPressed`，且**必须由玩家亲手按下**才启动警报，开始时不自动响。
- 操作教学扩为 6 页，最后一页按钮为「返回演练面板」，只关闭教学并恢复主面板，不调用 `StartGame()`。
- 教学面板不再挂在右手手柄锚点，改为相机正前方 0.80 米居中；打开教学时隐藏生命值、倒计时、火焰血条，关闭时恢复。
- 三台灭火器统一 `dropToFloor=false`、轴心 `y=0.46`、`isKinematic=true`、`useGravity=false`，并逐台避开书架、椅子、文件柜、桌凳；瓶体始终保持竖直。
- 知识墙与教学末页按韩国소방청（消防厅）「불나면 대피 먼저」五步与灭火器四步重写；地面引导箭头从任意出生点自动绕障指向大厅 / 安全出口。

### 2.6 韩国官方口径与逃生路线

依据：

- 소방청「불나면 대피 먼저」五步：
  1. 주변 사람에게 알린다（先提醒周围人）
  2. 대피방향을 결정한다（判断最近安全出口，走楼梯、绝不乘电梯）
  3. 신속히 대피한다（低姿快速撤离，不折返取物）
  4. 119 신고（撤到安全地带后再拨打 119）
  5. 대피 후 인원 확인（到集合点清点人数）
- 灭火器四步：안전핀 뽑기 / 노즐 잡고 불꽃 밑동 / 손잡이 움켜쥐기 / 분말 골고루；
- 站位：背风、背门、由上到下；门把手很热时不要开门。

对应到本项目中：

- 报警按钮先按、警报后响，符合「先报警、再疏散」；
- 情形 1 普通员工：报警 → 直接撤离，不尝试灭火；
- 情形 1 负责人：只在「初期小火 + 器材合适 + 视野清楚 + 身后退路安全」四条同时满足时灭火，灭完再撤；
- 情形 2：主火锁定为不可灭，A/B 都只按报警、低姿撤离；
- 地面箭头从任意出生点沿可通行折线指向大厅 / 安全出口，自动绕开桌腿、墙和门框；浓烟中箭头放大 2.2 倍并显示「安全出口 + 距离 + 方向」；
- 出口门外是空旷集合点，走到集合点才算完成撤离。

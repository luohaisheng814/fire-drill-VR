## 1. 本轮要解决的四个问题

| 用户描述 | 根因 | 修复 |
| --- | --- | --- |
| 「操作演练」属于什么情景的教学，标出来 | 开始界面只写了模式名，没有教学类型说明 | 开始界面「操作演练」按钮下方常驻标签「技能操作型情景教学 · 程序性技能训练」；新增 `Docs/05-操作演练的教学定位.md`；`DrillScenario.cs` 头注释写明定位 |
| 灭火器离火源太近，靠近取瓶被火焰烧伤；灭火器旁空白要补窗/墙 | 02/03 号瓶距火 1.68 m / 1.96 m，玩家取瓶站位会踩进 `fireDangerRadius = 1.55 m` 的危险半径；东墙南段有裸露空白 | 02 号瓶外推到距纸张火 2.55 m，03 号瓶外推到距茶水间火 2.59 m；东墙拆成南北两段，南段补窗洞 `WindowWall_East_South` + 窗 `Window_EastSouth`（u -3.68~-2.98），窗下正好放 03 号瓶；采光窗不再复制排烟粒子 |
| 茶水间走到安全出口没有灭火器 | `StageTwoFlow.MoveSpareExtinguisherToLobby` 在备用瓶被手持时直接 `return`；茶水间 `skipEvacuation = true` 会在火灭瞬间进入第三阶段，此时 03 号瓶还在手里（自动放下要 0.9 s），出口旁就没有瓶 | 改为：spare 空闲则用它；被手持则挑最近的空闲瓶搬过去；全都被拿住则强制放开 spare 再搬。落点从书柜与办公桌夹出的死角 `(4.95, 3.20)` 前移到门旁过道空位 `(3.75, 2.75)`，并冻结刚体，避免落地后又被物理推倒 |
| 单机灭火器进答题界面时，「距灭火器多远」提示不要弹 | 问答面板 `RefreshDistanceHint` 每次都刷新距离行 | `ExtinguisherQuizPanel.showDistanceHint = false`，`Open/Close/ResetQuiz/BuildUI/RefreshDistanceHint` 全部按开关处理，构建时即收起距离行；同时保持 `SetCoachSuppressed(true)`，防止教练 Toast 从旁边冒出距离文案 |

另外修正一处帧率无关的小问题：备用瓶搬到落点后立刻 `isKinematic = true`（`StageTwoFlow`），否则物理会在几帧内把它推成横躺，视觉上又像「出口没有灭火器」。

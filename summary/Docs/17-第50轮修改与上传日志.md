# 第 50 轮修改与上传日志

## 1. 本轮需求与做法

需求（用户原话要点）：

1. 完善 Unity VR 毕设《summary / 办公室消防知识演练》。
2. 操作演练的 6 个界面跳得太快，调整每个界面的跳转速度，保证每一页内容都能看清。
3. 界面与场景里的火焰增加多个火焰元素和烟雾效果。
4. 把情景 1 的起火地点做一次合理的现场规划，情景 2 同步处理。
5. 结合韩国官方消防安全知识，重新设计逃生路线、灭火知识与注意事项。
6. 以玩家视角测试，通过后上传到 `https://github.com/luohaisheng814/fire-drill-VR.git` 并生成本日志。

做法：

- 逐层排查「跳得快」的来源，确认不是 6 页操作教学（它本来就是手动上/下页），而是两套自动推进的答题面板；把答完后的讲解停留和结果页停留都放慢到 5 秒。
- 用「主火 + 多个装饰火簇 + 多股烟」的方式扩展火场，而不是只放大一团火；主火熄灭时装饰火一起熄灭。
- 情景 1 从「一个孤立黑柜子」补成可读的电气火灾现场：供电电缆、柜脚灼烧、烧焦纸箱、散落文件、过载标牌；情景 2 补焦黑桌面、烧焦档案夹、散落纸张。
- 逃生引导加入「火源危险区」判定，直线穿火时自动改走折线；同时把韩国소방청五步、门把手烫手、集合点清点等写进教学和知识墙。
- 用 `Round50Probe` 从玩家眼高 1.62 米、1600×900 走一遍并截图；全量自检通过后再提交。

## 2. 落地细节

### 2.1 六个界面的停留时间

| 参数 | 旧值 | 新值 | 作用 |
| --- | --- | --- | --- |
| `ExtinguisherQuizPanel.advanceDelay` | 1.3 s | **5.0 s** | 答完一题后，讲解与正确/错误反馈停留 5 秒再进下一题 |
| `ExtinguisherQuizPanel.resultDwell` | 1.2 s | **5.0 s** | 结果页停留 5 秒再自动收起 |
| `PreTrainingQuiz.advanceDelay` | 1.6 s | **4.5 s** | 事前教育答题也同步放慢，避免看完题就被切走 |

操作演练的「6 个界面」按 **5 道题 + 结果页** 处理；6 页 `OnboardingScreen` 操作教学保持手动翻页，不额外加自动计时。

配套修正：

- `FireSafetySetup` 在生成 / 复用灭火器时**显式写入** `advanceDelay = 5f`、`resultDwell = 5f`，避免场景里旧的序列化值（1.3 / 1.2）覆盖脚本默认值。
- 答完题后倒计时不再停在「剩余 10 秒」，改为「已作答」；结果页改为「本轮结束」，避免和「答题结束」自相矛盾。
- 答题面板打开时，`DrillToast` 不再弹出「烟雾吸入：生命值 -1」这类世界提示，防止它盖住题目、选项或结果。
- 自检仍用 `resultDwell = 0.01f` 跑旧问答逻辑，另加断言确认默认值是 5 / 5 / 4.5。

### 2.2 多火焰元素与烟雾

新增 `FireSafetySetup.AddFireDecor(...)`：从火源现有的 `Fire001` / `Smoke001` 粒子克隆装饰，只复制粒子，不复制 `FireSource`，不登记进 `FireSource.particles`；位置按根节点缩放换算成局部坐标。

| 火源 | 新增火焰 | 新增烟 | 视觉意图 |
| --- | --- | --- | --- |
| `DeviceFire` | **+5 簇** | **+3 股** | 柜顶左右、正面、桌面纸堆、柜脚电缆各一处，形成「机柜→纸箱/纸→地面电缆」的蔓延 |
| `PaperFire` | **+4 簇** | **+2 股** | 桌面纸张向四周延烧，火舌盖住散落档案 |
| `PantryFire` | **+3 簇** | **+2 股** | 台面小家电火 + 抽油烟方向烟 |
| `BaseFire000`（独立情形 / 操作演练模板） | **+3 簇** | **+2 股** | 第二阶段运行时克隆自动继承 |

- `FireSource.Extinguish()` 改为调用 `ClearFlame()`；`ClearFlame()` 会停自身和全部子粒子、灯光、声音，主火血量归零后装饰火一起消失，不会留下「主火灭了、旁边还在烧」。
- 全局烟雾层 `LobbyGlobalSmoke` 从「灰墙」调回「薄烟」：
  - 发射点 14 → 10；
  - 粒子 2.30 → 1.60 米；
  - 每秒 38 → 16；
  - 浓度 2.00 → 0.75；
  - 粒子上限 420 → 240；
  - 颜色 alpha 0.55 → 0.30。
- 近火浓烟仍由 `Stage1Smoke` 局部提供，玩家能看出烟，但不会看不清 HUD、题目和脚下箭头。

### 2.3 情景 1 起火现场规划

保留机柜 `DeviceCabinet (-2.40, 0.53, 2.90)` 与主火 `DeviceFire (-2.40, 1.06, 2.90)`，补全现场叙事：

| 物件 | 位置 / 做法 | 作用 |
| --- | --- | --- |
| `PowerCable` | 从机柜顶部接到北墙总闸的 `LineRenderer` | 读得出「电气线路过载」 |
| `CabinetScorch` | 柜脚地面灼烧圆盘 | 火从柜底向上蔓延 |
| `CharredBox` | `(-1.82, 0.17, 3.00)` | 柜边纸箱被引燃 |
| `ScatteredPapers` | 机柜与纸箱周围 5 张散落文件 | 火向可燃物扩散 |
| `CabinetWarningTag` | 机柜正面「线路过载 / OVERLOAD」 | 现场提示，朝向已修正为正面可读 |
| 装饰火 | 桌面纸堆、柜脚电缆、柜顶左右、正面 | 多火头，不再是一根火柱 |

- 全部道具无 `Collider`，不挡逃生路线；自检逐项断言 `PowerCable / CabinetScorch / CharredBox / ScatteredPapers / PaperScorch / PaperFireDebris` 均无碰撞体。
- `CabinetWarningTag` 的 `TextMesh` 曾出现镜像反字（`DAORREVO`），本轮把位置移到机柜正面、旋转归零，玩家视角已能正常读「线路过载 / OVERLOAD」。

### 2.5 韩国官方知识与逃生路线

依据 소방청「불나면 대피 먼저」五步：

1. 주변 사람에게 알린다（先提醒周围人）
2. 대피방향을 결정한다（判断最近安全出口，走楼梯、绝不乘电梯）
3. 신속히 대피한다（低姿快速撤离，不折返取物）
4. 119 신고（撤到安全地带后再拨打 119）
5. 대피 후 인원 확인（到集合点清点人数）

对应到本项目中：

- `OnboardingScreen` 第 5 页明确：本办公室唯一安全出口在东侧，门外 10.4 米为集合点；情形 1 门前无火可开门，情形 2 门前有初期火焰必须先灭再开门。
- 第 6 页保留五步与注意事项：门把手很热不要开门；烟雾中贴墙低姿、不折返取物；灭火器只用于初期小火，火大立即撤离。
- `PlazaKnowledgeBoard` 三语第⑤条同步为「集合点清点；门把手烫手不开门；火大撤离，初期小火才用灭火器」。
- `GuidanceArrows` 新增火源危险区：
  - `fireClearRadius = 1.8 m`；
  - `fireProbeStep = 0.35 m`；
  - `avoidBurningFires = true`；
  - `pathSideOffsets` 从 3 档扩到 4 档（0.8 / 1.6 / 2.4 / 3.2 米）；
  - 直线穿火时先左右绕行；横向绕行被家具挡住时，再走「先向南离开燃烧区 → 横穿大厅南侧 → 折回东侧出口」的四段疏散折线；
  - `AvoidingFire` 标记路径已避开火源；实在找不到折线时保留直线并写 Warning，便于自检报警。
- 自检用临时火源挡住 (20,0,0) → (20,0,6)，确认生成折线并 `AvoidingFire = true`；玩家视角从真实出生点到东侧出口的直线距火源 3.93 米，不穿 1.8 米危险区。

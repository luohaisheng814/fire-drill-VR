# 操作演练属于什么情景的教学（第 39 轮）

> 结论一句话：**「操作演练」属于技能操作型情景教学（procedural skill drill）**——用真实办公场景把「提瓶—答题—拔销—压把—对准根部—扫射」这套程序练成肌肉记忆，而不是讲知识点，也不是自由探索。

## 1. 它在教学类型谱系里的位置

| 教学类型 | 核心特征 | 本项目是否属于 |
| --- | --- | --- |
| 知识讲授型（lecture / tutorial） | 以概念、原理、条文为主，学习者被动接收 | 否（只在门外知识墙与问答里做知识支撑） |
| 自由探索型（sandbox / exploration） | 无固定目标与顺序，鼓励试错 | 否（有严格步骤门控） |
| **技能操作型情景教学（procedural skill drill）** | **真实情景 + 固定操作序列 + 步骤门控 + 即时纠错** | **是（「操作演练」模式）** |
| 考核测评型（assessment） | 以评分排名为主，过程不提供指导 | 部分（结算页有评分，但过程持续给指导，属形成性评价） |

按加涅的学习结果分类，它训练的是**动作技能（motor skill）**与**智慧技能（rule-using）**的组合：动作层面是拔销、压把、握持扫射；智慧层面是「什么火用什么灭火剂」「几米外开始喷」「不能站在火跟前」。

## 2. 判定为「技能操作型情景教学」的五条依据

1. **行为化目标**：完成条件写得很硬——取瓶 → 答对 60% 才允许拔销 → 拔销 → 压把 → 喷嘴对准火焰根部 → 火焰血量归零。目标不是「了解消防知识」，而是「能做完整动作序列」。
2. **真实情景与真实后果**：三套情景（电气设备 / 办公桌纸张 / 茶水间）用真实办公布局，火焰、烟雾、能见度、玩家生命值都参与判定；站得太近会掉血，这是情景教学里最关键的「后果反馈」。
3. **程序性任务链**：任务被切成固定顺序的环节，前一步不成立就不解锁下一步（问答门控 `CanPullPin`）。这是 drill 的典型结构，区别于自由探索。
4. **即时纠错反馈**：教练提示（`DrillToast`）、HUD 火焰血量条、距离与角度判定、错误灭火剂提示，都在动作发生的当下给出，而不是等到最后才判分。
5. **渐隐式支架（fading scaffolding）**：开始界面标注、地面青色灭火点位环、指向箭头、开始按钮上的默认情景提示，都是外部支架；玩家照着做几遍后，支架可以不再依赖，动作本身留下来。

## 3. 三个情景各自的教学侧重

| 情景 | 起火物 | 教学侧重 | 灭火剂 |
| --- | --- | --- | --- |
| 一 · 电气设备起火 | 插排 / 设备 | 先断电、再灭火；不能用水 | 干粉 / 二氧化碳 |
| 二 · 办公桌纸张 | 纸堆 | 站在上风口、由远及近扫射 | 干粉 / 水基 |
| 三 · 茶水间 | 电器与杂物 | 狭窄空间里的站位与撤离路线 | 干粉 / 二氧化碳 |
| 第 3 阶段 · 安全出口复燃 | 门前复燃 | 撤离途中二次处置、就近取瓶 | 干粉 |

三套情景共用同一条动作链，只是起火物、灭火剂、站位与撤离路线不同——这正是「同一程序、多种情景」的迁移设计。

## 7. 遗留说明

1. **北窗彻底不排烟了**：第 40 轮「窗口排烟」的效果在电气/茶水间两个情景仍在（东窗），北窗因为紧邻电源总闸、玩家会一直盯着它看，闪烁问题反复出现，本轮直接取消该窗的排烟。若后续希望「窗外冒烟」保留，建议放在不进入窗洞视线的位置（例如墙外 1.5 米处做低透明度烟柱），而不是贴在窗洞里。
2. **纸张情景截图里仍有 3%~5% 的浅蓝色像素**：这些不是透空，射线逐条回查全部命中 `wall_small (5)` 隔板的背面 —— 它是被室内冷色日光（`Light.color 0.94/0.97/1.0`）打亮的墙板。探针因此改成「浅蓝 + 视线打不到任何碰撞体」的双重判据，真透空为 0.00%。西墙 z -4~0 补洞后，这几张图的浅蓝已降到 **0.00%**（见第 8 节）。
3. `wall_small (2)` 与 `wall_small (3)` 之间的 x -4.75~-2.75 是原设计的 2 米通道（通往南翼），保持开口未封；通道两侧的补墙只补齐 1.75 米以上到 3.00 米的部分。
4. 桌面模式下点灭火器的判定仍走 `DesktopDrillInput`；「答题时屏蔽距离提示」同时覆盖了 XR 与桌面两条输入路径。

## 8. 补充修复（同日第二次验收：窗户仍闪 + 纸张处仍缺墙）

### 8.1 定位过程

第 44 轮第一版交付后用户复测仍报同样两条问题，于是新增了 `Round44Gap`：在纸张情景里站到 8 个玩家真会停留的点位（纸房中间 / 纸火桌旁 / 北面通道口 / 大厅 / Spawn01 / Spawn02 / 茶水间 / 走廊东端），每个点位朝 8 个方位拍 800×450 渲染，逐像素判「浅蓝 + 沿视线打不到任何碰撞体」，并把漏空射线 20 米处的世界坐标打出来。

首轮扫描（`Logs/shots/_round44_gap_before.txt`）共 **20 处漏空**，其中决定性的一条是：

```
站4(Spawn01 -6.0,1.6,-2.0) yaw270 天空19.1% 真透空99.4%
站4(Spawn01 -6.0,1.6,-2.0) yaw315 天空18.3% 真透空95.5%
```

对照 `Round44Recon` 的墙体包围盒：西墙 `wall_standard_wood_alt_1` 共五段，其中 `(1) z -2~0` 与 `(4) z -6~-4` 都是 **active=False**；`(4)` 在第 43 轮已被 `WindowWall_West_Solid`（z -6~-4）覆盖，而 **z -4~0 这 4 米从头到尾没有任何墙**。玩家出生在 Spawn01，转身朝西就是一大片天空盒 —— 这就是「纸张起火那块的墙壁还是没补上」的真实画面来源（不是纸火正后方那面，那面第一版已补齐）。

### 8.2 修复

- `FireSafetySetup.cs` 新增 `WallWest_MidFill`：`Axis.X`，`xWall -6.755`，厚 0.39（与原墙同厚），`z -4.00~0.00`，`y 0~3.00`。
- 材质用场景通用 `OfficeWallMat`（均匀浅灰）。**不能用** `wall_standard_wood_alt_1` 的 sharedMaterial：那是 palette 调色板贴图，原墙靠 UV 偏移只显示其中一块颜色，新 cube 会铺满整张图变成一整面彩色格子（第一版试过，画面右上角直接变成彩色棋盘，已回退换材质）。也**不能用** `CaptureWall`，它会 `SetActive(false)` 把相邻活墙停用，等于又开一个 2 米洞。
- 窗户闪烁：复跑时北窗 8 帧亮度总幅降到 **1.85%**、单帧最大 **1.34%**、反向 0 次（第一版为 2.50%/1.55%/1 次），窗面已稳定。

## 1. 本轮要做的四件事

| 用户描述 | 做法 |
| --- | --- |
| 纸张、电器、茶水间三个出安全出口后的空地上，各加本情景独有的消防常识，原有内容不变 | 新增 `ScenarioKnowledgeBoards.cs`：在门外广场原有知识墙（`PlazaKnowledgeBoard`，三块展板 + 地面字，完全保留）旁边，按情景生成一块专属立牌——情景一「电气设备起火」（先断电、CO₂/干粉、别用水、拔插头前别碰金属），情景二「纸张/固体可燃物」（A 类、水基/ABC 干粉、纸箱别堆走廊、扫射根部），情景三「茶水间油锅/小家电」（F 类、湿化学、盖锅盖断氧、别端锅跑）。每个情景只显示自己那一块，三语各一套文案 |
| 三个情景都加火灾警报背景音 | `FireAlarm` 作为常驻环境音接入流程：`DrillFlowDirector` 在进入「发现火灾」阶段时 `autoAlarmOnDiscover` 自动 `StartAlarm()`，任何情景开局都会响，一直作为背景音循环，直到演练结束/失败时停 |
| 新增启动时的语言选择页（中文 / 韩文 / 英文），之后所有内容按所选语言呈现 | 新增 `LanguageSelectScreen.cs`：挂在启动场景，`Awake` 里构建世界空间面板并自动弹出（把开始界面先藏起来），三个大按钮「中文 / 한국어 / English」；选择后写 `PlayerPrefs`（`fire_drill_language`）、广播 `DrillLocale.Changed`、刷新字体缓存、关闭面板并放出开始界面。`DrillLocale` 升级为三语（`T(中, 英, 韩)`，韩文缺失回退英文再回退中文），所有 UI 都从它取文案 |
| 按七步流程完善：事前教育（10 题 60%）→ 发现火灾 → 警示与报告 → 判断能否初期处置 → 尝试初期灭火 → 危险增加/失败时疏散 → 到达安全地点并报告 | 新增 `PreTrainingQuiz.cs`（10 道三语题、每题 20 秒、60% 通过率，答错给讲解）与 `DrillFlowDirector.cs`（阶段机 `Idle → Discovered → Alerted → Extinguishing / Evacuating → Reported`）；新增 `AlarmCallButton.cs`（走廊手动报警按钮，靠近并注视 0.8 s 即按下，拉响警报并提示拨打 119）；评估结论按「火势是否初期 / 灭火器是否 3.6 m 内 / 是否有退路」给出可尝试或直接疏散；灭火超时或生命值过低自动转疏散；走到门外集合点后标记「已报告」 |

## 2. 本轮修掉的四个实现缺陷

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 手动报警按钮站到跟前也按不动 | `AlarmCallButton._plate` / `_renderer` 是 private 字段，场景序列化时丢失，运行时 `target` 退化成柱子底部（y=0），玩家高度差导致注视夹角判定失真 | 字段加 `[SerializeField]`，并在 `Awake` 里 `transform.Find("AlarmPlate")` 兜底找回来 |
| 注视进度一直是 0 | dwell 用 `Time.deltaTime` 累加，在批处理/无头运行下取不到推进 | 改为记录 `realtimeSinceStartup` 起始时刻做差，帧率无关 |
| 真机玩家站到按钮前 1.2 m 仍判「太远」 | 判定距离算的是「相机到面板」的三维距离（含 1.5 m 高度差），原 `engageDistance = 1.8` 卡在边界 | 放宽到 `2.0 m` |
| 切换语言后，门外原有三块知识墙仍是中文 | `PlazaKnowledgeBoard` 只在 `Awake` 构建一次，没监听语言变化 | 全部文案改为 `DrillLocale.T(中, 英, 韩)`，订阅 `DrillLocale.Changed` 后销毁旧展板按新语言重建；`PanelLines()` 始终返回中文原文供自检 |

另外，`LanguageSelectScreen` 增加公开的 `ForcePlace()`：把面板重新摆到主相机正前方，供验收脚本在换机位截图前调用（真机上 `LateUpdate` 每帧自动跟随）。

| 验证 | 命令 | 结果 |
| --- | --- | --- |
| 场景装配 | `-executeMethod FireSafety.EditorTools.FireSafetySetup.RunSetup` | 场景重写保存成功（`Logs/setup47.log`） |

探针按玩家视角依次验收：

1. 启动即弹出语言页，三个语言按钮，开始界面被藏起；
2. 选韩文 → 语言写入、面板关闭、开始界面可再次显示；再切回中文；
3. 开始演练先弹事前教育，10 题作答 6 对 4 错 → `CorrectCount=6`、`RequiredPass=6`、`Passed=true`（60% 刚好通过）；
4. 进入情景即处于「发现火灾」，火灾警报 `IsRinging=true`（背景音）；
5. 走到走廊按钮前 0.89 m 注视 0.8 s → `Triggered=true`；
6. 阶段推进到评估：结论「火势处于初期、灭火器就在 3.4 米内、身后有退路 → 可以尝试初期灭火」，`CanAttemptInitial=true`；
7. 喷灭纸张火 → 阶段转「疏散」，安全出口解锁；
8. 走到门外集合点 → `ReportedAtAssembly=true`，最终阶段 = 「到达安全地点并报告」；
9. 三情景专属知识牌（电气 / 纸张 / 茶水间）与原有知识墙同框，中 / 韩 / 英三套语言来回切换后仍回到中文。

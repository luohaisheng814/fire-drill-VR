# 第 51 轮修改与上传日志

## 1. 本轮需求与做法

需求（用户原话要点）：

1. 完善 Unity VR 毕设《summary / 办公室消防知识演练》。
2. 灭火器布局参考韩国官方标准，并按比例缩小到本办公室。
3. 修复情形 2 玩家初始出生点被家具/桌板挡住、烟雾不明显、视野被阻挡的问题。
4. 情形 2 模拟火势变大、无法灭火，玩家只负责撤离；出口门右击即可打开，不附加其他条件。
5. 情形 2 的火焰数量偏少，需要增加。
6. 规划 1～2 条通向安全出口的路线来指导玩家。
7. 结合韩国官方消防安全知识，重新设计合理的逃生路线、灭火消防知识与注意事项。
8. 以玩家视角测试，通过后上传到 `https://github.com/luohaisheng814/fire-drill-VR.git` 并生成本日志。

做法：

- 以韩国《소화기구 및 자동소화장치의 화재안전기술기준(NFTC 101)》核对灭火器数量、步行距离、取用高度和标识要求；保留三台灭火器分别覆盖电气区、纸张区、茶水间的布点逻辑，抬高挂点并补「소화기」标识。
- 情形 2 出生点从贴近火源、正对桌板的位置，改到北侧开阔走道；用胶囊体占位检测和玩家眼高实拍复核，确保镜头前没有桌椅、柜体或墙板。
- 局部烟改为「更多、更小、更浅」的烟团，去掉原来火源上方的近黑色实心球；保留整体烟层，但让火、门和地面路线仍可辨认。
- 情形 2 彻底取消门前火与灭火条件：门只解锁、不自动开，玩家走近右击门扇即可打开并走出。
- 情形 2 主火增加 6 簇装饰火、3 股烟，火势更明显。
- 黄色主路线 + 青色备用路线同时铺向同一个东侧安全出口；修复「直线虽然无碰撞但穿过火源危险区仍被直接放行」的寻路漏洞，并给备用路线增加平行车道兜底。
- 事前教学、大厅阶段提示、门外三语知识墙统一写入 NFTC 101、A/B 双路线、右击直接开门、韩国官方五步与注意事项。
- 新增 `Round51Probe` 玩家视角探针，跑完整流程并输出证据图；全量 `FireSafetySelfTest` 通过后再提交。

## 2. 落地细节

### 2.1 韩国灭火器标准与办公室比例

依据 NFTC 101 及韩国法规解读，采用以下硬指标：

| 指标 | 要求 | 本办公室落地 |
| --- | --- | --- |
| 小型灭火器步行距离 | 室内任意位置到最近一台 ≤ **20 m** | 三台布点后最远点约 **7.9 m** |
| 大号灭火器步行距离 | ≤ 30 m | 本场景使用小型手提式，按 20 m 控制 |
| 按 1:2.5 缩放到办公室尺度 | 20 m 上限对应约 19.8 m | 7.9 m × 2.5 ≈ **19.8 m**，仍在上限内 |
| 取用高度 / 瓶底距地 | ≤ **1.5 m** | 瓶体根节点 `y=0.75 m`，实测瓶顶 **1.49 m** |
| 位置与标识 | 易见易取，挂「소화기」，前方不堆物 | 三台均贴墙竖挂，红底白字标牌，高度 **1.46 m** |
| 数量与分区 | 每层至少 1 台；分隔居室按面积增补 | **3 台**，分别覆盖电气区、纸张区、茶水间三个独立隔间 |

三台坐标（保留第 50 轮的隔间锚点，按标准复核距离与高度）：

| 灭火器 | 坐标 | 覆盖区 | 说明 |
| --- | --- | --- | --- |
| `Extinguisher01` | `(-4.85, 0.75, 3.42)` | 电气区 / 北墙西段 | 靠近设备柜与总闸，取用前方净空 |
| `Extinguisher02` | `(-6.26, 0.75, -1.15)` | 纸张区 / 西墙中段 | 柜旁净空，距纸张火约 3.4 m |
| `Extinguisher03` | `(6.75, 0.75, -3.87)` | 茶水间 / 东墙南端 | 桌凳与南墙之间，距茶水间火约 3.2 m |

- `SetupExtinguisherWallBracket(...)` 增加 `lift = bottlePos.y - 0.46f`，挂板与挂钩随瓶体同步抬高，保持「瓶底落在挂钩上」。
- 标牌对象名 `Extinguisher01_Sign / 02_Sign / 03_Sign`，使用新增材质 `ExtinguisherSignMat`（红底），文字白色。
- 韩文标牌最初用整串 `TextMesh`，在窄牌上逐字换行成竖排；本轮改为「一字符一个 TextMesh」横排，三个字 `소 / 화 / 기` 从左到右排列，玩家视角已可读。

最终三个出生点：

| 出生点 | 坐标 | 离主火源 | 到大厅引导点 |

- 三点全部落在北侧开阔走道，镜头正前方不再出现工位桌板、档案柜或墙板。
- 初始朝向沿用「看向火源一侧」的构图：一进入情形 2 就能看到火焰与烟，而不是先对着一面空墙。
- 探针用 `Physics.OverlapCapsule` 在 0.35～1.70 m 高度、半径 0.28 m 检查占位，并排除玩家自身 `XR Origin (Drill)`；三点均为 `blockers=0`。

曾试过但废弃的候选：

- `(-5.15, 2.55)`、`(-5.65, 2.90)`、`(-6.20, 2.00)`、`(-3.20, -4.00)`：实拍都有桌板/柜体贴脸，或火焰被家具挡住。
- `(2.30, 2.00)`、`(3.30, 3.00)`、`(4.30, 2.50)`：画面干净，但离大厅/出口只有 1.1～1.5 m，路线只剩一枚箭头，逃生训练意义不足。
- 西侧 `(-4.20, 3.50)`：胶囊检测虽为开放，但玩家眼高实拍正前方有一个深色柜体/箱体占住画面中心，已放弃。

### 2.3 情形 2 火焰与烟雾

`BaseFire000` 装饰从 3 簇火 / 2 股烟增加到 **6 簇火 / 3 股烟**，火焰缩放 `0.55`：

- 6 簇装饰火分布在桌面左、右、后、前与地面两侧，形成「桌面主火 + 四周延烧」；
- 3 股烟分别从火头上方与两侧升起，避免只有一根烟柱。

局部 `CaseSmoke` 原参数会在火源正上方聚成近黑色实心圆球，既挡火又不像烟。本轮改为：

| 参数 | 新值 |
| --- | --- |
| 颜色 | `(0.58, 0.58, 0.60, 0.38)` 浅灰半透明 |
| 发射速率 | `44` |
| 上升速度 | `0.58` |
| 粒径 | `0.92 m` |
| 生命周期 | `3.8 s` |
| 发射半径 | `0.30 m` |

整体烟层 `CaseSmokeZone` 保持：10 个发射点、每秒 30、`particleSize=1.55`、`alphaScale=1.10`、`particleCap=420`、`sizeGrowth=1.65`、离地净空 `1.05 m`。玩家视角下烟明显可见，但不再糊成一整块黑球；转身朝出口时，黄/青箭头与「安全出口」牌仍能读出。

### 2.4 情形 2 只撤离、门右击直接开

- `DrillScenario.StartFormal` 与 `BeginAlarmEvacuation` 两处均写入 `stageTwo.exitFirePresent = false`，情形 2 不再生成门前火，也不要求玩家灭火。
- `StageTwoFlow.EnterStageThree()` 走 `OpenExitWithoutFire()` → `ExitDoor.UnlockSilently()`：只解锁，门保持关闭。
- 玩家走近门扇、右击后由 `ExitDoor.TryOpenByPlayer()` 打开；探针在门前 `(4.30, 0, 1.02)` 调用返回 `true`，随后 `IsOpen=true`、`IsPassable=true`。
- 两处旧提示「门前火灭掉再开门」已改为：
  - 「主火扑不灭，报警后低姿沿安全出口撤离；门前无火，右击门扇直接开门」
  - 「……再沿安全出口低姿撤离；门前无火，右击门扇直接开门」
- 报警后的阶段提示进一步写明：「火势已发展，不要尝试灭火——转身朝东侧安全出口，低姿跟着地面黄色主线或青色备用线撤离；门前无火，右击门扇直接开门」。

说明：门仍要经过「按手动报警按钮 → 到达大厅」这一疏散流程才进入可开门状态；这是演练流程的步骤，不是灭火/答题条件。玩家到达门口后，开门本身只需右击，不再要求灭火或答题。

### 2.5 两条逃生路线

`GuidanceArrows` 保留并完善双路线：

| 参数 | 值 |
| --- | --- |
| `showAlternateExitRoute` | `true` |
| `alternateArrowCount` | `7` |
| `alternateArrowColor` | `(0.16, 0.86, 0.96)` 青色 |
| `alternateArrowScale` | `0.78` |
| `alternateSpacing` | `1.20 m` |
| `alternateStartDistance` | `1.25 m` |

路线规则：

- **黄色主路线**：由动态寻路决定，优先走最短可行线；遇到桌/墙绕行，并与正在燃烧的火源保持 `fireClearRadius = 1.8 m`。
- **青色备用路线**：先尝试贴着主火源北侧开放通道走，北线不通再走南线；两条横向绕行都失败时，沿主路径左右各试 `±0.45 / ±0.80 / ±1.15 m` 的平行车道，取第一条整段可行的线。
- 备用路径数组扩展到 8 个点，允许承载西侧长折线；备用箭头最多 7 枚，按 `alternateSpacing` 等距铺开。
- 本轮修复寻路漏洞：原 `BuildPath` 在「直线无碰撞」时直接返回，即使这条直线穿过火源 1.8 m 危险区也不改道。现在改为「物理无遮挡且不穿过火源危险区」才直接放行，否则继续算绕火折线。
- 大厅阶段的「安全出口」悬浮牌也不再写死「→」，改为按玩家实际来向显示「安全出口 3.6 米 ←」这类距离与方向，避免牌面箭头和真实出口方向相反。

玩家视角实测（`Round51Probe`）：

| 出生点 | 黄色主路线 | 青色备用路线 |
| --- | --- | --- |
| 出生点 1 | `main=4` | `alt=3`，路径点 4 |
| 出生点 2 | — | `alt=3`，路径点 4 |
| 出生点 3 | — | `alt=1`，路径点 4 |

从出生点正对火源时，画面以火情为主；转身朝东侧出口后，黄/青两条箭头与「安全出口 3.6 米 ←」牌同时可见，形成「先看到火、再转身沿箭头撤离」的引导节奏。

### 2.6 韩国消防知识重写

`OnboardingScreen`：

- 第 5 页明确情形 2「A、B 都不允许灭主火，按报警 → 低姿撤离」；出口门情形 1/2 门前都无火，走近右击即可，不要求灭火/答题/其他条件。
- 新增路线 A（黄色主箭头，大厅北侧/办公区外缘）与路线 B（青色备用，绕大厅南侧再从东墙折向出口），哪条看得清走哪条，不穿火焰、不折返。
- 第 6 页改为韩国官方五步：
  1. 提醒周围人；
  2. 判断最近出口，走楼梯、不乘电梯；
  3. 低姿快速撤离；
  4. 撤到安全地带后拨打 119；
  5. 到集合点清点人数。
- 第 6 页同时写入 NFTC 101：步行 ≤20 m、本办公室最远 7.9 m（1:2.5 ≈ 19.8 m）、取用高度 ≤1.5 m、挂「소화기」、前方净空；注意事项含门把手烫手不开、烟雾中贴墙低姿、灭火器只用于初期小火、情形 2 立即撤离。

`PlazaKnowledgeBoard` 三语面板同步写入 NFTC 101、A/B 双路线、右击直接开门；`PanelLines()` 自检确认三语内容存在。

# 灭火点位与第 3 阶段灭火修复（第 34 轮）

> 适用：`FireSafetyOffice` 三套起火情景（电气 / 纸张 / 茶水间）与安全出口前的第 3 阶段复燃火。
> 本轮同时解决「不知道站哪喷」和「第 3 阶段喷了不灭」两个问题。

## 1. 这轮改了什么

| 需求 | 实现 |
| --- | --- |
| 每个情景都要有明确的着火点与灭火站位 | 新增 `ExtinguishPoint` 组件：地面青色圆环 + 膝盖高度第二圈光环，挂在每个情景的起火点旁 2 米左右 |
| 玩家能看出「站在这里才算就位」 | 圆环只做视觉引导，不参与碰撞、不替代喷射判定；喷射仍按喷嘴到火焰的距离与夹角计算 |
| 第 3 阶段复燃火喷不灭 | 复燃火瞄准点从 0.32 m 抬到 **0.85 m**，并强制解除喷射锁定、重新点燃、重新挂接灭火焰事件 |
| 重开演练后第 3 阶段火「看着在但不烧」 | `EnterStageThree()` 每次都调用 `ArmStageThreeFire()`，不再依赖上一轮残留状态 |

## 2. 第 3 阶段为什么原来灭不掉

1. `StageTwoFlow.EnsureFire()` 克隆场景火焰模板，火焰中心在门本地 `+Z 0.75 m`、离地 `0.25 m`。
2. 原 `MakeAimPoint()` 把瞄准点写成 `local y = 0.32 m`。玩家正常持瓶时喷嘴约 1.2–1.3 m 高，站在 2 m 外要向下压约 24°。
3. `Extinguisher.sprayAngle` 默认只有 **20°**，喷锥边缘刚好扫不到 0.32 m 的火根，进度恒为 0，表现就是「白雾喷出去了，火不掉血」。
4. 同一 Play 会话里重开演练时，`stageTwoFire` 已存在且上一轮已被扑灭，`EnsureFire()` 直接返回；`EnterStageThree()` 只在 `!IsExtinguished` 时点亮，导致火不重新燃烧、`onExtinguished` 也没有重新挂上。

修复后：

- 瞄准点统一用 `stageTwoAimHeight = 0.85 m`，喷嘴角降到约 12°，落在 20° 喷锥内。
- `ArmStageThreeFire()`：`SetExtinguishLocked(false)` → 重挂 `onExtinguished` → `startUnlit = false` → `IgniteNow()` 清零进度并重新点燃。
- `EnsureStageThreePoint()`：按「火源 → 门」的反方向 2.0 m 生成/刷新 `StageThreeExtinguishPoint`，并绑定当前火源。

## 4. 验证结果

### 4.1 自检

`FireSafety.EditorTools.FireSafetySelfTest.RunAll`：**611 通过 / 0 失败**，末尾「全部通过」。

关键断言：

- 第三阶段火源瞄准点抬到玩家持瓶高度（喷锥才压得住）
- 第三阶段灭火点位距火 2.00 米
- 情景「电气 / 纸张 / 茶水间」：灭火点位绑定本情景火源

### 4.2 三情景第 3 阶段实喷

| 情景 | 1.2 s 时进度 | 最终进度 | 门锁 | 阶段 | 结果 |
| --- | --- | --- | --- | --- | --- |
| 电气 | 0.000 → 0.550 | 1.000 | 解锁 | `ExitOpen` | `FAIL_COUNT=0` |
| 纸张 | 0.000 → 0.554 | 1.000 | 解锁 | `ExitOpen` | `FAIL_COUNT=0` |
| 茶水间 | 0.000 → 0.477 | 1.000 | 解锁 | `ExitOpen` | `FAIL_COUNT=0` |

三次实喷的喷嘴到瞄准点距离均为 **1.57 m**，眼高 1.66 m，均在约 2–3 s 内把火扑灭。

## 1. 本轮需求与做法

| 用户描述 | 做法 |
| --- | --- |
| 语言选择页之后进入的那个页面，上面还有一个中英文切换按钮，删掉 | 该页是 `StartScreen`（开始界面）。`StartScreen.Build()` 不再调用 `BuildLanguageButton`，`BuildLanguageButton` / `MakeAbsoluteButton` 两个方法整块删除；切语言入口只保留在最前面的 `LanguageSelectScreen`。`ToggleLanguage()` 公开方法保留（`ExtinguisherGuideProbe` 在用），`_languageButton/_languageLabel` 只在 `SetVisible` 里判空，无空引用 |
| 电源总闸旁边那个窗户闪烁，修复 | 该窗是北窗（`Window_North`，窗洞中心 `(-3.65,1.85,4.00)`，紧邻 `DeviceCabinet(-2.40,0.525,2.90)` 与 `PowerSwitch(-2.40,1.35,3.68)`）。闪烁来自窗前大量流动的半透明粒子 + 玻璃与烟粒子同渲染队列：① `WindowSmoke_North/East` 起点从墙内移到墙外（北 z 3.58→4.32，东 x 6.86→7.42），参数从 64/秒、2.75 米降到 36/秒、1.65 米，颜色更淡（alpha 0.74→0.52）；② 室内导流烟带 `WindowFeed_North/East` 从「铺到离墙 0.35 米、高度压在窗洞下沿」改为「离墙 1.6 米就停、整体压到窗洞以下（y 1.02）」，窗前不再有流动烟层；③ `WindowGlassMat` 渲染队列固定到 `Transparent-10`（2990），永远先于队列 3000 的烟粒子渲染，消除同队列按距离重排造成的忽明忽暗 |
| 把缺失的纸张起火那块的墙壁补上 | 侦查（`Round43Recon2/3`）确认纸张火 `PaperFire(-5.710,1.06,-4.540)` 正后方是原来的西窗洞 `Window_West(-6.76,1.85,-4.60)`，窗洞里只有一块灰蓝天光板、玻璃 alpha 仅 0.20，从纸张火视角看就是「墙上缺了一块」。本轮把整扇西窗改成实墙：新增 `BuildSolidWall(...)`，用一整块 `WindowWall_West_Solid` 覆盖 z -6.00~-4.00、y 0~3.00、厚 0.39 米；西窗的窗框/玻璃/天光板/导流烟/排烟全部不再生成 |
| 提示距离灭火器还有多远，只在碰到、点击灭火器时触发，其他时间不触发 | `ToggleGrab.Update` 的按下判定由自维护的 `pressed && !prevPressed` 改为 `grabAction.action.WasPressedThisFrame()`。原写法在模拟量 Grip 阈值抖动时会一帧 true 一帧 false，于是每帧都算「刚按下」，站很远也一直广播 `GrabRejected`、反复刷「还差 X 米」。同时新增 `ReportGrabRejected(HandBinding)`：手离瓶身超过 `grabRange + rejectHintMaxHandDistance(3.0 米)` 直接不提示；同一提示有 `rejectHintCooldown(1.2 秒)` 冷却，不会连刷 |

1. 启动仍是语言选择页 → 选中文（切语言入口保留在这里）；
2. 进入开始界面：`Btn_Language` 数量为 0（截图里右上角不再有中英切换按钮），「决策训练 / 操作流程训练」两条入口仍在；

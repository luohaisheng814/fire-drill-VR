## 2. 六条设计修订的落实情况

| 修订 | 落实 |
| --- | --- |
| ① 测验移至事前教学模块，不作为疏散条件 | `PreTrainingQuiz.educationalOnly = true`：达到 60% 只是「教学达标」，未达标时结算页给两个按钮——「继续进入演练（教学记录已保存）」与「重新答题」，都能进场景；`StartScreen.requirePreTraining` 语义改为「进入前先上事前教育」，不再拦截 |
| ② 允许不灭火也能沿安全路线疏散，停止灭火并疏散视为成功 | `DrillFlowDirector` 新增三条成功路径：未喷火且走到安全出口 2.2 米内 → `EvacuatedWithoutExtinguishing`；喷过又停 5 秒 → `StoppedAttackAndEvacuated`；危险增加 → `DangerIncreased`。三者都进 `Evacuating`，`EndingSuccess` 都判成功 |
| ③ 反馈改为传达危险增加与疏散必要性，不以剩余生命值做继续灭火依据 | 判定改为三个非生命值信号：连续烟气 8 秒、首次喷射后 60 秒未灭、持续喷射 14 秒火势无进展（`progress01` 增长 < 0.02）。文案统一为「危险增加：……，继续灭火已不安全 → 立即停止灭火并疏散」。`evacuateHealthThreshold` 只留作旧场景序列化字段，不参与任何判定（`UsesVitalsAsDangerGate` 固定 false，自检有断言） |
| ④ 添加符合教学流程的最小警报与报告交互，或明确设为情境前提 | 报警：走廊 `AlarmCallButton` 注视 0.8 秒按响 → 全楼警报 + 119 报告（Toast 写明地址/起火物/火势/被困）；按钮缺席时自动按「情境前提：报警与 119 报告已由现场负责人完成」推进。报告：集合点报告作为第 ⑦ 步的结束状态，明确写出「集合流程依现场消防计划执行」 |
| ⑤ 设计到达安全地点与报告的结束状态；实际集合流程依现场计划 | 新增 `DrillEndPanel.cs`：到达集合点即弹出「演练完成 · 到达安全地点并报告」，逐条列出 报警 ✓ / 判断 ✓ / 操作（灭火成功 / 未灭火直接疏散 / 停止灭火 / 危险增加转疏散）/ 路线 ✓ + 集合流程说明，按钮「重新演练 / 留在集合点」。与 `EndingScreen`（倒计时到点的失败页）分开，不会清掉仍在燃烧的火 |
| ⑥ 优先实现核心疏散分支；绕行与求助依专家审查补充 | 核心疏散分支完整可用（出口解锁、低姿提示、集合点判定、结束状态）；绕行路线与「无法安全移动时向 119 报告位置请求救援」在结束面板与 README 中标注为「待专家审查后补充」 |
| 七步链路 | `Idle → Discovered（警报背景音）→ Alerted（报警+119）→ Assessed（判断）→ Extinguishing（可选）→ Evacuating → Reported`；`StageName` 把第 ⑤ 步改为「初期灭火（可选）」 |

探针按玩家视角依次验收：

1. 启动弹语言页（中文/韩文/英文）→ 选中文；
2. 开始界面显示两条入口：「决策训练」「操作流程训练」，说明写清两条训练线；
3. 纸张情景事前教育 → 标题「事前教育 · 办公桌纸张起火」，题库第 8 题为纸张题（A 类），`educationalOnly=true`；
4. 第一遍 6 对 4 错 → `Passed=true`（6/10 = 60% 达标）；
5. 第二遍只答对 3 题 → `Failed=true`，但仍出现「继续进入演练（教学记录已保存）」按钮，证明测验不挡路；
6. 进入纸张情景 → 阶段 `Discovered`，火灾警报 `IsRinging=true`；
7. 走廊按钮前注视 → `Triggered=true`、`AlarmReported=true`、阶段 `Alerted`；
8. 评估 → 「火势处于初期、灭火器在 3.4 米内、视野清楚、身后有退路 → 可以尝试初期灭火；也可以选择直接疏散」，`CanAttemptInitial=true`；
9. **不拿瓶、不灭火，直接走到安全出口** → 阶段自动转 `Evacuating`、`EvacuatedWithoutExtinguishing=true`、出口解锁；
10. 触发危险增加 → 阶段保持疏散、`EvacuationReason` 含「危险增加」、Toast 显示「危险增加：烟气持续累积、能见度下降，继续灭火已不安全 → 立即停止灭火并疏散」；
11. 走到门外集合点 → `ReportedAtAssembly=true`、阶段 `Reported`、`EndingSuccess=true`、结束面板弹出且回顾含 4 条 ✓ 与「现场消防计划」；
12. 三块情景专属立牌（中文）+ 韩文切换 + 与通用知识墙并存。

## 8. 遗留说明

1. **绕行路线与向 119 求助**：本轮只做核心疏散分支；「主要路线危险时选替代路线」「无法安全移动时在受保护区域向 119 报告位置」在结束面板与 README 里写明待专家审查后补充。
2. **实际集合流程**依现场消防计划执行：本演练给的是「到达指定集合点、清点人数、报告未撤离人员、不擅自返楼」的通用动作，具体集合点位与负责人由现场计划决定。
3. 事前教育测验只作教学记录：未达标也能进入演练，教学记录（答对题数）写日志与面板，便于后续训练复盘。
4. 桌面/无头体验下，世界空间面板（结束面板）后方若正好有世界文字牌，3D 文字可能穿透 UI 面板；真机站立集合点时面板正前是空地，影响很小（证据图为排除干扰临时隐藏了知识牌）。
